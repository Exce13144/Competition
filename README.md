## 使用

二进制题目均附带出题方提供的 libc / loader，建议用对应版本运行，避免环境差异：

```bash
./ld-linux-x86-64.so.2 --library-path . ./pwn
```

或用 `pwninit` 补齐调试环境：

```bash
pwninit --bin ./pwn --libc ./libc.so.6
```
